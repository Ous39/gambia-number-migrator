# Accessibility Review v2.8.0

The shared mobile controls use large touch areas, text labels with icons, accessible button roles/labels, plain states, system fonts, dark/light palettes, and minimal motion. Admin controls retain visible focus and responsive layouts.

Manual release testing remains required with TalkBack, VoiceOver, keyboard-only navigation, 200% text, display zoom, reduced motion, high contrast, dark mode, small phones, and modal focus restoration. Success/error/status must be announced and must not depend on color alone. Target WCAG 2.2 AA where web criteria apply.
