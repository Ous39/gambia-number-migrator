GNM ADMIN v2.8.5 UPDATE

This package updates only the admin portal. It preserves the current API,
database, mobile application, migrations, environment variables, and payment
integration.

Included changes:
- Fixed top navbar with System Owner identity, dark/light mode, and logout.
- Responsive mobile navigation drawer.
- Clear v2.8.5 release label in the admin sidebar.
- Notification audiences: all eligible users, free-trial users, subscribers.
- Notification platform targeting: Android, iOS, or both.
- Notification enable/disable control.
- Existing redesigned dashboard, login, tables, forms, cards, and dark mode.

HOW TO APPLY ON WINDOWS

1. Back up your repository folder or create a Git branch.
2. Copy the apps folder from this package into the root of your current
   gambia-number-migrator repository and allow Windows to replace the matching
   admin files.
3. Do not delete your existing apps/api, apps/mobile, database, or .env files.
4. From the repository root, run:

   pnpm install --frozen-lockfile
   pnpm --filter @gnm/shared build
   pnpm --filter @gnm/admin build

5. If both builds pass, run:

   git add apps/admin
   git commit -m "Upgrade GNM admin portal to v2.8.5"
   git push origin main

6. Railway should deploy automatically. Keep the existing Railway admin build,
   start command, target port 5173, and VITE_API_BASE_URL configuration.

VERIFICATION

- Open the Railway admin URL in an Incognito window.
- Confirm the sidebar says "Admin Console · v2.8.5".
- Confirm System Owner, dark mode, and Logout are in the fixed top navbar.
- Confirm Notifications includes trial/subscribed audiences and enable/disable.
