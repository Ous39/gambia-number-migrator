GNM v2.8.6 — LIVE PRICING + FREE ACCESS CAMPAIGNS
==================================================

WHAT IS FIXED
- The mobile payment screen requests the current price every time it opens.
- API responses disable caching for app configuration and device access.
- The API remains the authority and rejects an outdated payment amount.
- Devices with paid or promotional access cannot be charged again.

FREE ACCESS MODES
- Paid access: normal payment is required.
- First N users free: the first configured number of eligible registered devices receive permanent promotional access.
- Free for everyone: every eligible device receives promotional access while this mode is enabled.
- Turning the campaign off does not remove access already granted.

RECOMMENDED FIRST-100 LAUNCH
1. Deploy the API and run all migrations, including:
   database/migrations/016_dynamic_pricing_and_free_access.sql
2. Deploy the updated Admin portal and mobile app.
3. Open Admin > App configuration.
4. Set Campaign mode to "First N users free".
5. Set Number of free users to 100.
6. Set the Contact Migration Pass price.
7. Select Save settings.

IMPORTANT DEPLOYMENT ORDER
1. Database migration
2. API
3. Admin portal
4. Mobile build

VERIFICATION
- Change the price in Admin and save.
- Reopen Payment on the phone; the new price must appear.
- Enable First N users free and register a new test device.
- The app must display "Your access is free" and must not show payment checkout.
- Disable the campaign and confirm the already-granted test device remains active.

SECURITY
- Never add Firebase Admin SDK JSON, .env files, passwords, API keys, or credentials to Git.
- Keep Railway database migrations enabled during deployment.
