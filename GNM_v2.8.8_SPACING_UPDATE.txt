GNM v2.8.8 UI Spacing Update

This release standardizes spacing across the affected mobile screens while
preserving all payment, free-access, notification, backup, cleanup and admin
features from v2.8.7.

Updated screens:
- Dashboard
- Notification permission
- Notification Inbox
- Remove Old Duplicates
- Settings warnings and sections

Additional correction:
- Notification Inbox no longer tells users to manage notifications inside the
  app Settings page. Notification permission is managed through the standard
  first-launch system prompt and the phone's operating-system settings.

Release version: 2.8.8
Android version code: 33
iOS build number: 33
