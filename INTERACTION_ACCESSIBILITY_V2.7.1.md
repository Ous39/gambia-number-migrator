# GNM v2.7.1 — Calm Interaction and Inclusive Language

## Product principle

GNM is intended for nationwide use in The Gambia. The interface must be understandable without requiring technical knowledge. It follows a familiar, WhatsApp-like interaction model: stable screens, recognizable icons, large labelled actions, immediate touch feedback, and no decorative movement that slows the user down.

## Motion rules

- Page changes are immediate.
- Dialogs open without entrance animation.
- Buttons and cards do not shrink, bounce, slide, or move on touch.
- A brief opacity or colour change confirms a tap.
- Progress indicators move only when they communicate real work.
- Loading indicators remain available because they explain that work is continuing.
- The operating-system reduced-motion preference remains respected.

## Language rules

- Use short sentences and familiar words.
- Pair every important icon with a visible text label.
- State what will happen before asking for confirmation.
- State clearly when nothing has changed yet.
- Avoid unexplained technical terms.
- Use the core journey consistently: Scan → Check → Back up → Update → Confirm.

## Safety rules

- No contact changes occur before user confirmation.
- Risky actions keep confirmation dialogs.
- Colour is never the only way to communicate status.
- Loading, success, warning, and failure states retain text and icons.
