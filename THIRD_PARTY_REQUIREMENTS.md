# Third-Party Requirements

Wave: official API and webhook documentation, sandbox/merchant account, approved callback URL/IP policy, authentication/signature examples, payment states, idempotency rules, checkout/OTP responsibility, expiry/refund/reconciliation process, and production credentials.

APS: the same official integration, security, sandbox, callback, lifecycle, settlement, and production-approval material.

Expo/FCM/APNs: Expo project ownership, access token where required, Android FCM credentials, Apple developer team, APNs key/certificate, bundle entitlements, signing profiles, and physical test devices.

PURA/operators: written confirmation of every production prefix/range, effective date, parallel-running end date, exceptions, approvals, and change-control contact.
