# UI Design System v2.8.0

- Brand: deep navy `#071A33`, dark navy `#07111F`, electric blue `#1769FF`, light canvas `#F5F7FB`, white.
- Body text: system font, normally 16 px/dp equivalent; clear headings; scaling enabled; no meaning by color alone.
- Spacing: 4/8/12/16/24/32 scale. Touch targets: minimum 48×48.
- Radius: 12–24 for controls/cards. Shadows are subtle and optional; borders carry structure.
- Buttons: visible text plus familiar icon where useful; full surface clickable; opacity/color press feedback; no shrinking/bounce.
- Forms: persistent labels, plain errors, keyboard-safe layout, focus ring, disabled/loading state, double-submit guard.
- Cards/tables: low visual density; real data only; responsive table wrapping/card conversion on narrow screens.
- Navigation: text labels remain visible; clear Back/Cancel/Done; no trapped workflow.
- Progress: determinate where measurable; spinner only for unknown waits; no fake delays.
- Empty/error/success: state title, plain explanation, one clear next action.
- Motion: functional 100–200 ms color/opacity/modal changes only; reduced motion uses instant changes.
- Breakpoints: compact mobile below 380, standard mobile 380–767, admin tablet 768–920, desktop above 920.
- Language: short verbs, no backend jargon, explain safety and recovery, never imply unverified payment or notification success.
