Source: Public Utilities Regulatory Authority letter Ref. P/TR/NP/VOL.XV/(457), dated 9 July 2026, “Notification of new 9-digit number allocation.”

Effective date: 4 September 2026. Parallel running ends: 30 November 2026.

| Operator | Existing 7-digit ranges | Prefix added | New form |
| --- | --- | --- | --- |
| QCell | 3XXXXXX, 5XXXXXX | 83 | 83 + existing number |
| Comium | 6XXXXXX, 84XXXXX, 85XXXXX, 86XXXXX, 87XXXXX | 86 | 86 + existing number |
| Africell | 7XXXXXX, 2XXXXXX, 40XXXXX, 41XXXXX, 45XXXXX | 87 | 87 + existing number |
| GAMCEL | 9XXXXXX | None in Phase 1 | No change |
| GAMTEL fixed | Existing fixed ranges | None in Phase 1 | No change |

The app encodes only the explicit old-number ranges above. It does not treat every number beginning with 8 or 4 as a match. This prevents migration of unallocated or unrelated numbers.
