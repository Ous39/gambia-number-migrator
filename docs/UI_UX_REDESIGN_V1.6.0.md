# UI/UX Redesign — v1.6.0

The v1.6.0 release introduces one coherent design language across the mobile app and admin console while preserving the audited v1.5.0 migration, backup, scan, preview, payment and notification behavior.

## Design direction

- Gambian green is reserved for primary actions, progress and success.
- Deep navy-green surfaces communicate privacy and operational trust.
- White and neutral surfaces improve reading comfort and data scanning.
- Amber and red remain reserved for warnings and destructive decisions.
- Operator colors remain recognizable without competing with primary actions.

## Mobile improvements

- Consistent responsive spacing, cards, form controls and 54px touch targets.
- Persistent labels on all five bottom navigation destinations.
- Clear privacy language in top-level headers.
- Reduced decorative elevation and more compact radii for a professional utility feel.
- Unified accessible light and dark palettes.

## Admin improvements

- Replaced emoji navigation with consistent vector icons.
- More compact, responsive sidebar and tablet/mobile navigation layouts.
- Improved table headers, hover states, inputs, buttons and keyboard focus rings.
- Unified metrics, hero cards, badges, notices, login and dark mode styling.

## Functional safety

No migration rules, contact-writing behavior, transaction handling, backups, payments, API authorization or notification delivery logic was changed by this visual release.
